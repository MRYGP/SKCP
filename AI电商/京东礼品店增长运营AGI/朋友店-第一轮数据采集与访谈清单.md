# 朋友店 · 第一轮数据采集与访谈清单

## 一、开场话术

想拿你这个店当第一块试验田，一起琢磨怎么把它做大。先不急着判断是不是“一键推广”，我想先把你真实生意跑一遍：订单从哪来、客户在哪、哪些平台有数据、哪些东西现在靠你脑子记。越具体越好，随便聊。

## 二、先画全渠道经营地图

先不要只看京东后台。先问清这家店到底在哪些地方做生意。

- 现在只做京东，还是也有淘宝 / 天猫 / 拼多多 / 抖音 / 快手 / 小红书 / 微信 / 线下 / 熟人订单？
- 每个渠道大概占多少订单、多少收入、多少利润？不用精确，先估比例。
- 哪个渠道带来新客户？哪个渠道带来复购？哪个渠道利润最高？哪个渠道最烦？
- 同一个商品是否在多个平台卖？标题、价格、库存、SKU、主图是否一致？
- 有没有线下客户、企业客户、熟人客户在微信里成交，但没有进入京东后台？
- 有没有客户先在一个平台咨询，最后在微信或线下成交？
- 有没有因为多个渠道割裂，导致库存不准、价格不一致、客服重复、客户漏跟进、利润算不清？

产出：一张“渠道 → 商品 → 客户 → 订单 → 交付”的经营地图。

## 三、后台数据：京东先拿，但不只拿京东

近 30 天，能导就导；导不了就截图也行。京东是第一块，但如果有其他渠道，也要拿最小数据。

### 京东 / 京麦 / 生意参谋

- 访客数、商品曝光 / 展现量、点击率。
- 咨询量、咨询 → 下单转化率、访客 → 支付转化率。
- 客单价、退款率、复购率（有的话）。
- 流量来源构成：搜索 / 推荐 / 活动 / 付费 / 站外 / 熟人各占多少。
- 出单最多的 3-5 个商品 + 它们的流量主要从哪来。
- 之前如果开过车 / 报过活动：花了多少、带来多少访客和订单。

### 其他平台 / 私域 / 线下

如果有淘宝、天猫、拼多多、抖音、微信、线下或熟人订单，至少拿这些：

- 近 30 天订单数、销售额、退款/售后数。
- TOP 3 商品。
- 客户来源：平台自然流量、付费、老客、熟人、企业客户、社群。
- 是否有客户名单或聊天记录沉淀。
- 是否能看出毛利：售价、成本、运费、平台扣点、人工/定制成本。

## 四、访谈问题

### A. 现状：搞清生意到底通在哪、卡在哪

1. 现在一周大概出多少单？稳定出还是偶尔出？这些单分别从京东、微信、线下、其他平台来多少？
2. 哪个渠道你最想放大？为什么？是流量多、利润高、客户质量好，还是操作最省心？
3. 有多少人看你的商品（访客 / 曝光）？看了的人里，大概多少会咨询、多少真下单？
4. 有没有平台后台看不到、但你知道很重要的生意信息？比如熟人客户、企业客户、微信成交、线下复购。

### B. “一键推广”：到底想解决什么

5. “一键推广”具体是想花钱买流量（开车 / 快车），还是想让更多人自然刷到，还是其实是“不知道钱该投哪、怕投了没效果”？
6. 之前试过推广吗（开车、报活动、发社群）？花了多少、有没有用、为啥停了？
7. 如果同一个商品在多个渠道都能卖，你会怎么决定钱投在哪个平台？现在靠什么判断？

### C. 数据割裂：判断这个项目的根

8. 你现在想知道“这个店做得好不好”，要分别打开哪些后台、表格、聊天记录？
9. 有没有一个问题，是单看京东后台回答不了，但你经营上必须知道的？
10. 有没有发生过：客户在 A 渠道问、B 渠道买、微信里改需求，最后你很难追踪？
11. 库存、价格、交期、客户需求，现在是怎么同步的？靠系统、表格，还是靠你记？
12. 你最想有一张什么表：全渠道订单表、客户复购表、商品利润表、库存交期表，还是本周动作表？

### D. 关键三问：判断这事的根

13. 你觉得你这店为啥能出单——是哪几样东西做对了？
14. 如果现在给你 1000 块、一周时间，让单量翻倍，你第一件事会做什么？为什么不是做别的？
15. 礼品定制这行，你见过做得特别好的店吗？他们做对了啥是你做不到的？

### E. 找帮手的点

16. 你每周在这店上花最多时间的是哪件事？哪件最烦、最想有人帮你做掉？
17. 哪件事不是最耗时，但一出错损失最大？比如报价、交期、定制需求、库存、发票、售后。
18. 如果 AI 每周只帮你做一件事，你最希望它先帮哪件：看数据、改商品、跟客户、算利润、同步库存、生成话术，还是告诉你本周先做什么？

## 五、竞品对照：找 3-5 个做得比她好的店

请她提供，或我们自己在京东 / 淘宝 / 拼多多 / 抖音搜同类关键词找。边界是 3-5 个真实竞品店，不做大市场报告。

- 她觉得做得好的 3-5 家礼品定制店。
- 这些店在哪些平台卖？是单平台强，还是多平台都做？
- 这些店主要卖什么品类 / 价格带。
- 标题怎么写：关键词、场景词、定制词。
- 主图怎么做：是否突出定制、企业采购、节日、现货、案例。
- 详情页写了哪些她没写的信息：定制流程、交付周期、起订量、logo / 刻字 / 包装说明。
- SKU 怎么组合：单件 / 套装 / 批量 / 企业礼盒。
- 评价区有什么高频好评 / 差评。
- 她觉得这些店“做对了什么”，以及“自己暂时做不到什么”。

产出不是竞品报告，而是“她店这周能抄的 3 个动作”。

## 六、现有工具与工作流

- 现在每天主要用哪些工具：京麦、生意参谋、快车、客服工具、表格、作图工具、AI 工具？
- 如果有多个平台，每个平台分别用什么后台 / 工具？
- 商品上架、改标题、改主图、改详情页，分别是谁做？多久做一次？
- 客服报价有没有固定话术 / 表格 / 模板？
- 定制需求怎么记录：微信、京东聊天、表格，还是靠记忆？
- 订单交付流程怎么走：客户确认 → 设计 → 打样 → 生产 → 发货，中间最容易卡在哪？
- 现在有没有用 ChatGPT / 文心 / 豆包 / Kimi / 剪映 / Canva / 稿定等工具？用来干什么？
- 哪一步最重复、最烦、最容易出错？
- 哪些数据现在散在不同地方，导致你不愿意看、不知道怎么算、或者经常漏？

## 七、回来后要产出什么

- 画出真实漏斗：曝光 → 点击 → 咨询 → 下单 → 复购。
- 画出全渠道经营地图：京东 / 其他平台 / 微信 / 线下 / 熟人分别承担什么。
- 定位真卡点：不是照“一键推广”造，而是看数据和回答共同指向哪里。
- 找出 3 个数据割裂点：必须是影响经营动作的割裂，不是为了做看板而做看板。
- 验导师锚：她的判断是导师层，还是执行层。
- 形成第一版动作输入：能直接给她店用，也能沉淀进礼品定制类目动作库。
- 形成第一版“统一经营状态表”字段：只保留能导出动作的字段，不做重 ERP。

## 八、边界

- 这是第一轮试验田采集，不做大市场报告。
- 不默认京东就是全部生意，也不默认跨平台一定存在；按事实来。
- 问题越具体越好，允许口语化、允许不完整，先拿真实信息。
- 不承诺自动出单，不先卖工具；先用数据判断卡点。
- 不把“跨平台数据割裂”当口号，必须落到具体损失和具体动作。
