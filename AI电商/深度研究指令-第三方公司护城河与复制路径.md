# 研究委托：AI 赋能电商——第三方公司护城河与可复制路径扫描（国内外）

## 第 0 节 · 方向历史状态（先回答，不要跳过）

本方向已有一份前序研究报告，核心结论是：**平台原生 AI（阿里妈妈、京东言犀、Shopify Magic/Sidekick、Amazon Rufus 等）正在系统性吞噬独立 AI 工具，靠 LLM API 薄封装的产品（如 Jasper）极其脆弱**。

所以本次**不是重做全景扫描**。本次只聚焦一个问题：**在平台绞杀下，哪些第三方公司/产品活下来了、且有可验证的真护城河？它们靠什么活下来？**

## 一、研究问题（研究什么 / 不研究什么）

**研究**：国内外**第三方公司 / 产品**，在「AI 赋能电商商家」（B 端，帮商家开源节流）领域，已经活下来、有真实收入、且有可验证护城河的玩家。

**明确排除**（一律不算）：
- 平台原生 AI（阿里妈妈/万相台、京东言犀全系、抖音即创/剪映、拼多多官方、Shopify Magic·Sidekick、Amazon Rufus 等）
- 纯 C 端购物助手（面向消费者，不面向商家）
- 仅靠融资活着、无收入/留存验证的
- 2023 年前的老 SaaS 且没有真正 AI 升级的

## 二、核心判据：每个入选公司必须标注"护城河归属"

对每个公司，必须回答：**它的护城河是静态数据型还是持续变化数据型？这份数据/能力，平台自己是不是天然就在沉淀？**

- 护城河 = 平台天然也在沉淀的那份 → 标「**易被平台吞**」，并说明它靠什么暂时没被吞
- 护城河 = 平台**拿不到 / 不屑拿**的（跨平台数据、特定小类目深度 know-how、线下与服务环节）→ 标「**平台盲区型**」（这是本次重点研究对象）

## 三、对每个强玩家，挖"怎么爬到壁垒位置的路径"，不是表面形态

要的是它从 0 到护城河走了哪几步、靠什么数据闭环 / 客户绑定建起壁垒——不是它的产品长什么样（表面形态最易复制也最易被复制）。

**速查表字段**：

| 公司/产品 | 国内外 | 服务的用户群（具体到品类/规模/平台） | 解决什么具体卡点 | 收入模式 | 护城河类型（静态/持续变化 · 平台天然沉淀否） | 怎么爬到壁垒的路径 | 抗降维（会不会被通用大模型/平台顺手做掉） | 飞轮（用的人越多越好用否） | 证据等级 | 换个用户群/战场能否照搬结构 |

每类至少 3 个案例（国内外都要）。覆盖：内容生成、运营自动化（选品/定价/投放/竞品监控）、客服与销售、视觉与体验、供应链履约、培训与赋能。

## 四、复制价值专项（服务"抄结构 × 换战场"打法）

本研究服务于"对标 → 复制换用户群"打法（拼多多抄京东换下沉市场）。对最强的 TOP 5 玩家，各回答：

1. 它服务的用户群是谁？有没有一个被它忽视的**相邻用户群 / 品类 / 区域**，护城河结构能照搬过去？
2. 中国能不能复制？严格区分：能否复制产品 / 能否复制底层逻辑 / 中国第一个垂直场景在哪 / 谁付钱 / 谁是接盘侠 / 平台多久能复制 / 小团队第一步能验证什么。
3. 禁止空泛结论"中国市场很大所以有机会"。必须落到：哪个具体用户、哪个具体场景、当前替代方案是什么、谁愿意付费。

## 五、逆向案例：至少 5 个第三方公司"被平台吞 / 收缩 / 转型"案例

延续前序报告的 Jasper 式死法分析，但本次要**新的、第三方的 B 端电商工具**案例（不要再用 Jasper/鹿班）。每个写清：死因机制、是被谁替代的、对应什么结构性弱点。

## 六、长尾三层扫描（中国机会必做）

中国机会扫描须覆盖三层，不能只看大企业：
- 第一层：中型以上正规企业
- 第二层：中小企业（50–500 人）
- 第三层：长尾——小作坊 / 个体工商 / 夫妻店（年营收 <500 万、无 IT、老板拍板）

只扫 1–2 层须写明「未扫第 X 层，原因：____」。

## 七、跑通者考古提示（研究员自警）

AI 研究报告对"藏在付费社群、评论区、代运营公司内部的真实跑通者"是**结构性盲区**。凡遇"这个细分好像没人做 / 案例稀少"，先写一句：**"这可能是报告盲区，不等于市场空白，建议人工从从业者社群验证"**，不要据此当成机会下结论。

## 八、输出要求

1. 按完整研究报告结构输出：研究摘要 → 关键发现（每条含证据等级+来源）→ 速查表（第三节字段）→ 复制价值专项（第四节）→ 逆向案例 → 长尾三层扫描 → 矛盾与争议 → 待验证假设 → 证据账本 → 下一步研究问题。
2. 所有关键结论标注证据等级（A 原始源 / B 多源交叉 / C 单一源·推断 / X 无来源·不得当事实）。找不到就写"未找到"，不许编造。
3. 不做 Go/Kill 最终决策——只给证据、矛盾、风险、待验证假设。
4. 文末加「评分判别力声明」：若候选评分集中在某区间、拉不开差距，须声明判别力不足，勿仅凭分数排序。
