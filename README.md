# SK 产品库

GitHub 仓库：[MRYGP/SKCP](https://github.com/MRYGP/SKCP)

收纳所有产品方向——无论废弃、暂停、还是跟进中。
原则：先入库，状态写在文件内部，不靠文件夹名表达死活（与 SK 主仓"版本号不进文件名"同理）。

## 状态定义

- 🌱 菜地候选：漏斗现成 + 6个月可见现金流信号 + 未判死
- ⏸️ 暂停：曾推进或推演过，因主线集中等原因搁置，未被否决（默认状态）
- 🔦 手电筒已判死：API 嫁接、无系统复杂度，已判定不做（仅杨手动标记）
- 📚 底库：非独立产品，喂给别的产品的知识/资料库
- 🗄️ 扫描归档：一次性研究/扫描产物，非产品方向
- 🧬 模式层：商业模式母体，下挂多个垂直落地，不与落地平铺

注：判死（🔦）只能由杨逐个核实后手动标记，不预判。建库时一律先标 ⏸️暂停。

## 层级定义

- 产品：可被售卖或验证的具体产品方向，进入产品编号。
- 模式：商业模式母体，下挂多个垂直落地，不与具体产品平铺。
- 母体与前身：生产产品的研究院/工作台，或已被后续项目吸收的前身，不作为被售产品。
- 底库：喂给产品、工具或方法论的资料与知识底座，不作为独立产品。
- 扫描归档：一次性研究、扫描和推演归档，不作为产品方向。

## 漏斗字段

现成 / 需自建 / 不清楚 —— 用于一眼区分"嵌入现有漏斗"vs"要自建漏斗拉新"

## 入库规则

- 每完成一轮场景G推演 → 入库
- 每完成一轮扫描 → 归档进库
- 主仓（D:\sk）内的产品方向用指针纳入索引，不搬文件

## 维护触发器

与 D:\sk\ops\执行状态总表.md 联动（仅指针，不复制内容）。

详见 [产品库索引.md](./产品库索引.md)
